# 2026年からの脱出

[ゲームをはじめる](https://20230104curl.github.io/escape-2026/)

Windows版タブレットのChromeで横向きにして遊ぶ、8エリア・24問の謎解きゲームです。

はじめにゲームと同じ9つの文字ボタンで、5文字の入口パスワード「だっしゅつ」を入力します。正解すると学年（小4〜中3）と人数（1人／2人）を選べます。間違えた場合は消して何度でも入力し直せます。探索タイマーは入口では始まりません。エリアの途中でも、画面上部の「ほかのエリアへ」から自由に移動できます。残り時間は常に青い枠と大きな数字で表示し、残り5分から赤い枠に切り替わります。初回はエリアの選択から最初の問題を開くまで案内します。進行中の記録には初回の案内を追加しません。

各エリアの3問を解くと、文字を1つ手に入れられます。獲得した文字はその場からカタカナで表示し、できごと一覧でも文字と個数を確認できます。集めた文字が、最後のパスワードの手がかりです。

探索25分の後、背景を暗くした赤い緊急警告と約3秒の警報音で、最後の挑戦を知らせます。警告を確認してから、5つのできごとを起こった順にクリックする挑戦60秒、最後のパスワード60秒に進みます。最後に見つけた文字数が表示され、集めた文字がカタカナで1つずつ枠に入ります。まず赤くゆっくり点滅する「文字を入れる」を押すと、見つけた文字が解答欄の正しい位置に入り、右側の文字入力が使えるようになります。見つけた文字がある場合は、あてはめるまで文字入力・消去・決定はできません。文字が0個の場合は最初から入力できます。その後、残りの空欄を自分で入力して有名な言葉を完成させます。最初から入っているのは「・」「ー」だけで、8文字すべて集めても「オブリージュ」の「ブ」は自分で入力します。両方正解なら脱出成功です。解答を決定しても、最後の60秒が終わるまで結果は表示されません。脱出成功のときだけ108回目の除夜の鐘を1回鳴らします。音源冒頭の無音を削り、音声とイラストを先読みして再生開始に合わせて成功画面を表示します。音は約5秒でフェードアウトし、再生中も「つぎへ」で進めます。失敗・時間切れ・結果の再読み込みでは鳴りません。自動再生が制限される端末では「108回目の鐘を鳴らす」ボタンを表示します。

並べ替え画面は「まず、いちばん早く起きたできごとをクリック！」から案内し、選ぶと「次に起きたできごとをクリック！」へ切り替わります。最後の挑戦に失敗したときは、カウントダウン終了後に「残念！」だけを全画面で5秒表示し、その後に除夜の鐘の画面へ進みます。読み直してもこの表示は最初から繰り返しません。

進み具合は、その端末・ブラウザーに保存します。別の端末との同期はありません。

各エリアの3問をクリアした後は、正解の説明と手に入れた文字を表示したまま待ちます。「できごと一覧に戻る」ボタンを押して進みます。

最後のエンディングには「終わる」ボタンを表示します。押すと音・画面の更新・開いているメニューを終了し、ゲームのタブを閉じます。ブラウザーによって自動で閉じられない場合は、ゲーム画面を消し、「終了しました」「このタブを閉じてください。」だけを表示します。

[先生用の制限なしテストプレイ](https://20230104curl.github.io/escape-2026/start.html?test=1)では、時間とヒントの制限を外し、通常と別の記録で確認できます。

## ローカルで起動

Node.jsを用意して `npm start` を実行し、`http://localhost:4173/` を開いてください。
