# 2026年からの脱出

[ゲームをはじめる](https://20230104curl.github.io/escape-2026/)

Windows版タブレットのChromeで横向きにして遊ぶ、8エリア・24問の謎解きゲームです。

学年（小4〜中3）と人数（1人／2人）を選んで開始します。エリアの途中でも、画面上部の「ほかのエリアへ」から自由に移動できます。残り5分になるとタイマーが赤い枠と大きな数字で表示されます。

探索25分の後、緊急警告を確認してから、5つのできごとを起こった順にクリックする挑戦60秒、最後のパスワード60秒に進みます。最後に見つけた文字数が表示され、集めた文字がカタカナで1つずつ枠に入ります。「文字をあてはめる」を押すと見つけた文字が解答欄の正しい位置に入り、残りの空欄を自分で入力して有名な言葉を完成させます。最初から入っているのは「・」「ー」だけで、8文字すべて集めても「オブリージュ」の「ブ」は自分で入力します。両方正解なら脱出成功です。解答を決定しても、最後の60秒が終わるまで結果は表示されません。全編音なしです。

進み具合は、その端末・ブラウザーに保存します。別の端末との同期はありません。

[先生用の制限なしテストプレイ](https://20230104curl.github.io/escape-2026/start.html?test=1)では、時間とヒントの制限を外し、通常と別の記録で確認できます。

## ローカルで起動

Node.jsを用意して `npm start` を実行し、`http://localhost:4173/` を開いてください。
