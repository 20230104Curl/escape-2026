# 2026年からの脱出

[ゲームをはじめる](https://20230104curl.github.io/escape-2026/)

Windows版タブレットのChromeで横向きにして遊ぶ、8エリア・24問の謎解きゲームです。

学年（小4〜中3）と人数（1人／2人）を選んで開始します。探索は25分、最終問題は60秒。解答を決定しても、60秒が終わるまで結果は表示されません。全編音なしです。

進み具合は、その端末・ブラウザーに保存します。別の端末との同期はありません。

[先生用の制限なしテストプレイ](https://20230104curl.github.io/escape-2026/start.html?test=1)では、時間とヒントの制限を外し、通常と別の記録で確認できます。

## ローカルで起動

Node.jsを用意して `npm start` を実行し、`http://localhost:4173/` を開いてください。
