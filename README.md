# 2026年からの脱出

[ゲームをはじめる](https://20230104curl.github.io/escape-2026/)

Windows版タブレットのChromeで横向きにして遊ぶ、8エリア・24問の謎解きゲームです。

学年（小4〜中3）と人数（1人／2人）を選んで開始します。エリアの途中でも、画面上部の「ほかのエリアへ」から自由に移動できます。残り5分になるとタイマーが赤い枠と大きな数字で表示されます。

各エリアの3問を解くと、文字を1つ手に入れられます。獲得した文字はその場からカタカナで表示し、できごと一覧でも文字と個数を確認できます。集めた文字が、最後のパスワードの手がかりです。

探索25分の後、緊急警告を確認してから、5つのできごとを起こった順にクリックする挑戦60秒、最後のパスワード60秒に進みます。最後に見つけた文字数が表示され、集めた文字がカタカナで1つずつ枠に入ります。まず赤くゆっくり点滅する「文字をあてはめる」を押すと、見つけた文字が解答欄の正しい位置に入り、右側の文字入力が使えるようになります。見つけた文字がある場合は、あてはめるまで文字入力・消去・決定はできません。文字が0個の場合は最初から入力できます。その後、残りの空欄を自分で入力して有名な言葉を完成させます。最初から入っているのは「・」「ー」だけで、8文字すべて集めても「オブリージュ」の「ブ」は自分で入力します。両方正解なら脱出成功です。解答を決定しても、最後の60秒が終わるまで結果は表示されません。脱出成功のときだけ108回目の除夜の鐘を1回鳴らします。音源冒頭の無音を削り、音声とイラストを先読みして再生開始に合わせて成功画面を表示します。音は約5秒でフェードアウトし、再生中も「つぎへ」で進めます。失敗・時間切れ・結果の再読み込みでは鳴りません。自動再生が制限される端末では「108回目の鐘を鳴らす」ボタンを表示します。

進み具合は、その端末・ブラウザーに保存します。別の端末との同期はありません。

[先生用の制限なしテストプレイ](https://20230104curl.github.io/escape-2026/start.html?test=1)では、時間とヒントの制限を外し、通常と別の記録で確認できます。

## ローカルで起動

Node.jsを用意して `npm start` を実行し、`http://localhost:4173/` を開いてください。
